# ratAItool — Кулінарний AI-помічник

ratAItool — це AI-чат-помічник для роботи з рецептами та кулінарними запитами.

Застосунок побудований на **Streamlit**, використовує **Google Gemini** як мовну модель, **Google Sheets** як єдину базу рецептів та **Tavily** для пошуку рецептів в інтернеті за запитом користувача.

## Основні можливості

- пошук рецептів у Google Sheets;
- пошук рецептів за назвою, інгредієнтами та описом;
- пошук за дієтичними обмеженнями:
  - без лактози;
  - без глютену;
  - без лактози та без глютену одночасно;
- аналіз рецепта, який уже обговорювався в чаті;
- збереження контексту поточної розмови;
- розуміння посилань на попередній рецепт, наприклад:
  - «ця страва»;
  - «цей рецепт»;
  - «вона»;
  - «чи підходить вона?»;
- розрахунок кількості інгредієнтів для іншої кількості порцій;
- пошук в інтернеті через Tavily після явного погодження користувача;
- обмеження кількості запитів за одну сесію;
- обмеження довжини повідомлення;
- обмеження кількості повідомлень, які передаються в контекст моделі;
- діагностична інформація в Streamlit для контролю використання AI.

# Google Sheets

Google Sheets використовується як структурована база рецептів.

Приклад:

| name | ingredients | description | lactose free | gluten free |
|---|---|---|---|---|
| Запечені яблука з медом і корицею | яблука, мед, кориця, горіхи | Запекти яблука... | yes | yes |

Під час запуску застосунок:

1. підключається до Google Sheets;
2. завантажує таблицю;
3. нормалізує назви колонок;
4. перевіряє наявність необхідних колонок;
5. замінює порожні значення;
6. нормалізує значення `lactose free` та `gluten free`;
7. кешує дані на короткий період.

Якщо Google Sheets недоступний або структура таблиці неправильна, застосунок показує помилку.

# Пошук рецептів

За пошук відповідає інструмент:

```python
recipe_search()
```

Він може шукати:

- назву рецепта;
- інгредієнти;
- опис;
- безлактозні рецепти;
- безглютенові рецепти;
- рецепти, які одночасно відповідають декільком дієтичним критеріям.

Наприклад:

```text
рецепт борщу
```

або:

```text
знайди щось без лактози
```

або:

```text
потрібна страва без лактози та без глютену
```

У випадку пошуку за дієтичними критеріями фільтрація виконується безпосередньо по відповідних колонках Google Sheets.

# Контекст розмови

Для кожного нового запиту формується контекст із попередніх повідомлень.

Наприклад:

```text
Користувач:
Мені потрібна страва без лактози та без глютену.

ratAItool:
Знайдено...

Користувач:
А чи підходить вона для дітей?
```

AI має розуміти, що:

```text
"вона"
```

стосується рецепта, який був обговорений раніше.

Для контролю кількості токенів використовується обмеження:

```python
MAX_CONTEXT_MESSAGES = 20
```

Тобто в prompt передаються тільки останні повідомлення поточної розмови.

---

# Обмеження використання

У застосунку передбачені базові обмеження.

## Кількість запитів

```python
MAX_REQUESTS_PER_SESSION = 20
```

Один користувач може зробити максимум 20 запитів протягом однієї Streamlit-сесії.

Це обмеження допомагає контролювати використання Gemini API.

## Довжина повідомлення

```python
MAX_MESSAGE_LENGTH = 1000
```

Максимальна довжина одного повідомлення — 1000 символів.

## Контекст

```python
MAX_CONTEXT_MESSAGES = 20
```

У prompt передаються останні 20 повідомлень.

# Tavily Web Search

Google Sheets є основним джерелом рецептів.

Якщо рецепт не знайдений у базі, ratAItool не повинен автоматично вигадувати рецепт.

Користувачу пропонується:

```text
На жаль, у моїй базі даних немає рецепту, який відповідає цим критеріям. Бажаєте, щоб я пошукав його в інтернеті?
```

Tavily використовується тільки після явного підтвердження користувача.

Наприклад:

```text
Користувач:
Так, пошукай.
```

Після цього agent може використати:

```python
TavilyTools()
```

# Розрахунок порцій

Для математичного перерахунку використовується окремий tool:

```python
calculate_recipe_portions()
```

Він приймає:

```text
original_portions
desired_portions
ingredient_amount
```

і використовує пропорцію:

```text
новий обсяг =
початковий обсяг × бажана кількість порцій
/ початкова кількість порцій
```

Наприклад:

```text
2 порції → 4 порції
100 г → 200 г
```

# AI Agent

Agent створюється на основі Agno:

```python
Agent(
    name="ratAItool",
    model=Gemini(
        id="gemini-3.1-flash-lite"
    ),
    tools=[
        recipe_search,
        calculate_recipe_portions,
        TavilyTools()
    ],
    instructions=instructions,
    markdown=True
)
```

Agent має доступ до трьох основних інструментів:

### `recipe_search`

Пошук у Google Sheets.

### `calculate_recipe_portions`

Розрахунок кількості інгредієнтів.

### `TavilyTools`

Пошук інформації в інтернеті.

# Принцип роботи з галюцинаціями

Для зменшення галюцинацій agent отримує чіткі інструкції:

- Google Sheets — єдине джерело рецептів;
- не вигадувати рецепти;
- використовувати `recipe_search` для пошуку рецептів;
- використовувати дані `lactose free` та `gluten free` з бази;
- не використовувати Tavily без підтвердження користувача;
- використовувати історію розмови для контексту.

Таким чином, AI відповідає не тільки на основі власних знань моделі, а використовує структуровані дані з Google Sheets.

# Deployment у Streamlit Cloud

Основні кроки:

1. Репозиторій знаходиться на GitHub.
2. У репозиторії є `app.py`.
3. У репозиторії є `requirements.txt`.
4. У Streamlit Cloud вибирається GitHub repository.
5. Як main file вибирається:

```text
app.py
```

6. API keys додаються через Streamlit Secrets.
7. Після deployment Streamlit запускає:

```bash
streamlit run app.py
```

Секрети не потрібно зберігати в GitHub.

# Обмеження проєкту

Поточна реалізація має декілька обмежень:

- контекст зберігається в межах Streamlit-сесії;
- ліміт запитів прив'язаний до сесії, а не до постійного акаунта користувача;
- Google Sheets не є повноцінною реляційною базою даних;
- якість пошуку залежить від структури та повноти таблиці;
- Tavily залежить від доступності API та його лімітів;
- AI може неправильно інтерпретувати складні або неоднозначні запити;
- інформація про алергени не замінює професійну медичну консультацію.
